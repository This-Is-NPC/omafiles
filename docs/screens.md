# Screens

This guide walks every screen in omafiles in order of use, with pictures, keys, and how to reach each by keyboard and mouse.

The studio window is 1180×720 pixels, its default size. Pictures are generated by `mise run shots` from QML in the test harness, seeded with synthetic fixtures (see [scripts/shots.sh](../scripts/shots.sh) and the test `writesTheDocumentationShots` in [tests/tst_studio.cpp](../tests/tst_studio.cpp)). Every picture pins: the window size, the fixture tree at `/tmp/omafiles-docs/workshop`, the dark theme that applies when no omarchy colour file is present, and specific files and tags shown on screen.

## Main window

The main window shows files and folders in a list, details, or icon view. The top row is the tab strip: every tab with its **×**, a **+ Ctrl t** button that opens a menu of new tabs, and **Keys ?** at the right, which opens the key sheet. The current tab has the list's background and its name in bold; the others are grey. A tab that lists a tag shows the tag's colour square instead of the folder icon. Click a tab's **×** or middle-click the tab to close it. Under the strip is the toolbar, which works the focused pane: back, forward and parent folder buttons, the Undo button, then the path as one button per folder (**/**, **home**, **you**). The current folder's button is filled and outlined in the accent colour; click another to go there, or click the current one to type a path. When the path does not fit, the buttons at its start give way to one **…** button, which goes to the last folder hidden behind it; the current folder's button always stays whole. A tag listing, a search or the recent list is one button reading the question, such as **#work**. At the right of the toolbar: a filter field reading the filter, which opens the filter bar as **/** does; a sort button reading the sort key and direction, such as **name ↑ ⌄**, which does what **s** does; the view mode switch, three icons for list, details and icons view that are one Tab stop, where **←** and **→** move between them; and the **Details I** toggle, which shows or hides the details dock. The filter field is dropped first when the window is narrow, then the Details toggle; **I** still works. The sidebar on the left holds where to go: places, devices, tags and saved views, in that order. Each section starts with a heading in small bold text, such as **Views**, with the key that walks it drawn as a key at its right edge; a heading is not a Tab stop. The **Tags** heading carries a **+ Tag** button, which adds a tag to the current row or the marked set; it stays visible but greyed out while the current row is not a file or folder, and its tooltip then says **Select a file to tag it**. An empty section says so in text that wraps, such as **nothing saved yet · m to save one**; the devices section is hidden while no removable device is connected. See [Places](#places), [Tag panel](#tag-panel), [Saved views](#saved-views) and [Devices panel](#devices-panel). The details dock under the panes shows what the current row is; see [Details dock](#details-dock). Both follow the focused pane: a split window has one sidebar and one details dock, and the dock spans every pane. The sidebar is dropped while a pane would be narrower than 480 pixels; **p**, **v**, **d** and **t** bring the sidebar back while they walk it. One accent ring marks where the keyboard is: 2 px around a focused button or field, or 1 px on the edge of the cursor row of the focused list. In a split, the other pane's cursor row keeps its fill and has no ring. Buttons have one look: a raised box with a thin border, a stronger accent-bordered fill while on or pressed, and grey text while they cannot be used. A list, the sidebar, the dock's tags, a menu or a sheet whose content is taller than it shows a scroll bar at its right edge, in a strip of its own that rows never run under, and shows none when everything fits. Drag the thumb to scroll, click above or below it to move a page, or middle-click or Shift-click to jump to that point; the bar never takes the keyboard. In the file views a chevron above the bar goes to the first row and one below it to the last, as **Home** and **End** do. The pictures' fixture fits its window, so no picture shows the bar. The footer is one line: on the left the position, such as **2/5**, the number of marked rows in the accent colour when there are any, and **N tagged here**; on the right, hints for the keys of the focused region, each a key and a grey caption with no box around it until the pointer is over it. A hint is still a button: click it or Tab to it. While a sheet, a menu or the command palette is open, the hints name its keys, such as **Esc close** and **Enter apply**. A receipt or an error sits between them and takes the room of the least important hints. When the window narrows, the least important hints are dropped first; **? keys** always stays. The status drops whole facts from its end in the same way, so a fact is never cut mid-word; the position, such as **2/5**, always stays, and ends in an ellipsis where even it does not fit.

In list view every row shows its icon and name, then its tags, size and modified time in columns; details view shows the columns chosen for it under headings (see [Details pane](#details-pane)). In both, the tags column starts at the same place on every row, so each row's first chip lines up under the one above it. A folder's size is what it holds, such as **3 items**, **1 item** or **0 items**, hidden names included; it fills in once the folder has been read, without holding up the list, and stays empty for a folder that cannot be read. When the list narrows, the name keeps its room and list view drops whole columns: modified, then size, then tags.

Reach it: The main window opens when the application starts.

Keys: **j k / ↓ ↑** (down, up), **g g** (first row), **G** (last row), **Ctrl d** (half page down), **Ctrl u** (half page up), **PgDn PgUp** (page), **Home End** (first, last row), **← →** (prev, next in icons view), **l / Enter** (open row), **h / Bksp / ←** (parent folder), **H L** (back, forward), **~** (home folder), **1** (list view), **2** (details view), **3** (icons view), **s** (sort), **S** (flip sort direction), **I** (details dock), **.** (hidden files), **Ctrl h** (hidden files), **Ctrl l** (type a path), **F5 Ctrl r** (reload).

## Details pane

Press **2** to switch the file list to a table: name, then tags, type, size, and modified, one row per file. The name column has priority: it keeps at least 160 px, or 40% of the list when the list is narrower than 400 px. When the other columns do not fit beside it, they are dropped with their headings in a fixed order: mode, owner, modified, type, size, then tags. The name grows to at most 420 px; wider lists give the extra width to the tags. Sizes are right-aligned under a right-aligned heading. A dropped column still sorts with **s** and **S**. The row's tags, type, and other details always show in the details dock too, under the file list, whichever view is active. A tag shows as a chip: a raised box with a small square in the tag's colour before its name. The colour comes from the tag's name and the desktop theme's terminal colours, so a tag has the same colour in the rows, the details dock and every window; two tags can share a colour.

Reach it: Press **2** in the main window, or click the details button (the middle icon) of the view mode switch in the toolbar.

Keys (same as the main window): **j k / ↓ ↑** (down, up), **l / Enter / →** (open), **h / ← / Bksp** (parent folder).

Picture: **img/02-details.png**

## Details dock

The details dock is a band under the panes, as wide as all of them, with a thin line above it. It shows the current row of the focused pane in three columns. The first holds the file's icon in a square, its name in bold, and its path in grey. The path breaks only after a **/**, takes at most three lines, and drops folders from its middle behind **…** when it is longer. Under the path, the facts come in pairs: **Type** (the mime type) and **Size** (or **Items** for a folder), **Modified** and **Owner**, then **Mode** (the permission bits) and **Marked**. A click on a permission bit changes it at once; the bits are greyed on a link and on a file that is not yours. The second column, **Tags**, holds the row's tags as chips. Click a chip, or Tab to it and press **Enter**, to list the files with that tag, as a click on the tag in the sidebar does. Each chip ends in **×**: click it, or press **Delete** while the chip has the keyboard, to remove the tag from the row, or from the marked set when the row is marked. The **+ Tag** button adds a tag, as **t a** does; it is greyed out while the current row is not a file or folder. The column scrolls when the tags do not fit. The third column holds **Open**, **Open with** and **Rename**, each with its key where it has one; they do what **l**, the row menu's **Open with…** and **r** do.

Press **I** to hide the dock and give its room to the list, and **I** again to show it. A window too short to keep a column heading and four rows of list above the dock drops it until it is tall enough again. In a narrow window the dock drops the actions column first and then the tags column; their keys still work, and the rows still show their tags. Narrower still, the **Mode** and **Marked** row goes; the row menu's **Permissions…** still sets the bits.

Reach it: It is shown by default; press **I**, click **Details I** in the toolbar, or choose **Show or hide details** in the command palette.

Keys: **I** (show or hide), **Tab** (next chip or button), **Enter** (open the tag, or press the button), **Delete** (remove the tag in focus), **Esc** (back to the list).

Picture: **img/01-studio.png** (the dock under the list)

## Sorting

Press **s** to cycle the sort order: name, tags, type, size, then modified, and back to name. Press **S** to flip the sort direction. The sort button in the toolbar reads the key and the direction, such as **name ↑ ⌄**, in every view, and a click on it goes to the next key, as **s** does. In details view you can also click a column header to sort by that column directly; click it again to flip the direction.

Reach it: Press **s**, click the sort button in the toolbar, or click a column header in details view.

Keys: **s** (sort), **S** (flip direction).

## Row menu

Right-click a row, press **m**, or hold and press on a touch/pen to open the menu for that row. From the keyboard the menu opens at the row's name, below the row, or above it when it does not fit below; from the pointer it opens at the pointer, or above it near the bottom of the window. It stays 12 px inside the window and shows whole rows; a menu longer than the window scrolls.

The entries come in groups with a line between them, in this order: open (Open, Quick preview, Open with…, Go to containing folder, new tab, other pane, parent in new tab, graph tab, terminal, editor); send (LocalSend, scripts); copy (path, name, URI, tags, tag command, open command); tags (add, remove, rename, apply, clear, copy onto the marked, adopt); mark (mark, mark all, clear, invert, same tag, same type, by pattern); archive (Compress, Extract archive); files (copy, cut, paste, to the other pane, duplicate, links, rename, permissions, new folder, trash); browse (filter or browse by tag, save a view, find, recent); index (reindex, prune, verify, reload). A group with nothing to offer for the row is left out, and so is its line.

Reach it: Press **m**, right-click, or touch/pen long-press a row.

Keys: **m / Menu / Shift F10** (open menu).

Menu keys: **j k / ↓ ↑** (next, previous entry; the lines between groups are not entries), **Home End / PgUp PgDn** (first, last, page), **Enter / Space** (choose), **Esc** (close). An entry with a key of its own shows it on the right: **l** (open), **i** (quick preview), **Space** (mark), **Ctrl c** (copy), **Ctrl x** (cut), **Ctrl v** (paste), **r** (rename), **n** (new folder). Compress and Extract are chosen from the list; they have no key of their own.

## Command palette

Press **:**, **Ctrl p**, or choose **Commands** to open the command palette. Type to search all commands: Quick preview, Mark all, Sort by name, Undo, Save this as a view, Open Trash, and many others. The list shows whole rows: as many as fit, and the rest scroll. Use **Ctrl Home / Ctrl End** to jump to the start or end of the list. **Enter** runs the selected command.

Reach it: Press **:**, **Ctrl p**, or click the **Cmd** button in the footer.

Keys: **:** (open), **Ctrl p** (open), **Enter** (run), **Ctrl Home** (first command), **Ctrl End** (last command).

Reach it: Press **i** on a file, or open the row menu and select Quick preview.

Keys: **i / Esc** (close), **j k** (next, previous), **← →** (previous, next), **P** (play, pause), **[ ]** (seek), **PgDn PgUp** (scroll), **Home End** (scroll to ends), **Tab** (preview controls).

## Key sheet

Press **?** to show all keyboard shortcuts grouped by region: move, places, devices, archives, go, preview, mark, view, edit, find, tabs and panes, graph tab, trash, and window. In each section the keys stand in one column, as wide as the section's widest keys, and what they do starts on one edge after it. Keys that do the same thing share a row, separated by a slash: **r / F2** rename. Use **↑ ↓ / PgUp PgDn / Home End** to scroll. Press **Esc** to close.

## Places

The first sidebar section is a grid of buttons, two to a row: **Home**, then the desktop's user folders that exist (**Desktop**, **Documents**, **Downloads**, **Music**, **Pictures**, **Videos**, as `~/.config/user-dirs.dirs` or their default names say), then **Trash**. A user folder that is missing, or set to the home folder itself, has no button; the list is read again each time the tab moves. Click a place, or press **p**, move with **j k**, and press **Enter**: a folder opens in the current tab, and in a tags tab it opens in a new files tab. **Trash** opens the Trash in a new tab. The button for the folder the tab stands in has the accent border and fill. While **p** walks the grid, the button under the cursor has the 1 px accent ring.

Reach it: Press **p**, or click a place in the sidebar.

Keys: **p** (places), **j k / ↓ ↑ / PgDn PgUp / Home End** (move), **Enter / Space / l** (open in this tab), **h / Esc / ←** (return to files).

Picture: **img/01-studio.png**. Its fixture home folder holds **Documents**, **Downloads** and **Pictures**, so the grid shows Home, those three and Trash.

## Tag panel

Press **t** to focus the tags sidebar. The current row's own tags, with buttons to open and remove each, are in the [details dock](#details-dock). Each tag is a row: its colour square, its name, a bar whose length is its count over the largest count in the index, drawn in the tag's colour, and the count. The tags of the current row are in bold, and a grey caption under the list names the file, such as **Bold: on one.txt**. The heading's toggle orders the tags **by count**, most used first and ties by name, or **by name**; press **s** in the panel or click the toggle to switch. The **Find a tag** field under the heading shows only the tags whose names hold its text, in any case: press **/** in the panel or click it, type, then **Enter** toggles the tag under the cursor and **Esc** returns to the files with the text kept. Use **j k / ↓ ↑** to move through tags. Press **Enter / Space** to toggle a tag filter. Press **a** to add a tag, **d** to remove a tag, or **r** to rename a tag. Press **m** or **Menu** to open the tag menu. Press **h / Esc / ←** to return to the file list.

Reach it: Press **t** to focus the sidebar, or click a tag in the sidebar.

Keys: **t** (tag panel), **j k / ↓ ↑ / PgDn PgUp / Home End** (move), **Enter / Space** (toggle filter), **s** (order by count or by name), **/** (find a tag), **a** (add tag), **d** (remove tag), **r** (rename tag), **m / Menu / Shift F10** (tag menu), **h / Esc / ←** (return to files).

More: See [Editing tags in the window](tagging.md).

## Graph view

Open a graph view from the command palette. The graph shows files (rounded rectangles) and tags (circles) as nodes, with lines connecting files to their tags. Press **j k** or **← →** to move between nodes. Use **Shift h j k l** (or Shift with the arrow keys) to pan the view. Use **+ - =** or scroll to zoom. Press **l** or **Enter** to open the selected file or list the selected tag. Press **Ctrl w** to close the graph tab.

Reach it: Press **:** or **Ctrl p** to open the command palette, type **graph**, then press **Enter**. The **+** tab button also offers a **Graph tab** entry.

Keys: **j k / ← →** (move between nodes), **Shift h j k l** (pan), **+ - =** or scroll (zoom), **l / Enter** (open), **0** (reset view), **Ctrl w** (close tab).

More: Tags are shown as circles. Files are shown as rounded rectangles. Lines show tag relationships.

## Marking

**Space** marks the current row. **J K** mark the current row and move down or up. **a** marks all rows. **A** clears all marks. **\*** marks rows matching a pattern you type in the footer. A marked row has a light accent fill across the whole row and nothing else; the cursor row has a stronger one. Marked rows stay marked when you scroll or change tabs.

Reach it: Any screen in the file list.

Keys: **Space** (mark), **J K** (mark and move), **a** (mark all), **A** (clear marks), **\*** (mark pattern).

## Trash

Open Trash from the **+** tab menu or press **:** and choose **Open Trash**. The Trash tab shows files deleted from your computer and mounted drives. Each row shows the original path and deletion date. Press **r** to restore a row. Press **Enter** to see the original path and deletion details. Press **e**, then confirm, to empty Trash (permanent). There is no key to leave the Trash tab; switch to another tab or close it.

Reach it: Click the **+** tab button and select Trash, or press **:**  and choose **Open Trash**.

Keys (in Trash): **j k / ↓ ↑ / PgDn PgUp / Home End** (move), **r** (restore), **Enter** (original path), **Space** (mark), **a** (mark all), **A** (clear marks), **e** (empty), **F5** (refresh), **m / Menu / Shift F10** (row menu).

### Receipts and properties

A receipt dialog shows the full text behind a status message: the result of an operation, or an error. It appears in a centered window with a Close button, as tall as its text up to 480 pixels or the window's height; longer text scrolls inside it. The same dialog, titled Properties, opens when another application asks the desktop to show a file's properties. It darkens the window behind it the way a sheet does; a sheet that was already open stays drawn beneath it, and gets its focus and typed text back when the dialog closes.

Reach it: Click the message in the footer after an operation finishes.

Keys: **Tab / Shift Tab** (move between the text and Close), **Enter / Space** (close), **PgDn PgUp / Home End** (scroll).

More: See [Browsing large folders](browsing.md).

## Tabs and panes

### Open a new tab

Press **Ctrl t** to open a new files tab directly. For a tags, graph, or trash tab, click the **+ Ctrl t** button after the pane's tabs for a menu, or open the command palette (**:** or **Ctrl p**) and run **New tags tab**, **New graph tab**, or **Open Trash**.

Keys: **Ctrl t** (new files tab), **Esc** (close the menu or palette without choosing).

Picture: No picture yet.

### Switch tabs

Press **Ctrl Tab** (next) or **Ctrl Shift Tab** (previous). Press **\[** and **\]** to step tab. Press **Alt 1** through **Alt 9** to jump to a tab number.

Keys: **Ctrl Tab / Ctrl Shift Tab** (step), **\[ \]** (step), **Alt 1…9** (jump).

### Split panes

Press **Ctrl \\** to split the current pane into two side by side. Each pane has its own tabs: the tab strip shows them side by side in pane order, each pane's group with its own **+** button. The focused pane's current tab has its name in bold, the other pane's does not; no ring is drawn around a pane, and the toolbar works the focused pane. Press **Alt h** or **Alt l** to switch panes. Press **Ctrl ,** and **Ctrl .** to narrow or widen the focused pane. Each step moves the divider beside it by 40 pixels, and no pane goes below 280 pixels. In a window too narrow for every pane at 280 pixels, the panes share its width. Press **Ctrl Shift w** to close a pane.

Keys: **Ctrl \\** (split), **Alt h l / Alt ← →** (switch panes), **Ctrl ,** (narrow focused pane), **Ctrl .** (widen focused pane), **Ctrl Shift w** (close pane).

### Close tab and pane

Press **Ctrl w** to close the current tab, or click the **×** on any tab, or middle-click it. Press **Ctrl Shift w** to close the current pane.

Keys: **Ctrl w** (close tab), **Ctrl Shift w** (close pane).

## Drag and drop

Drag a file from the list, details, or icons view. A marked row carries the marked set; an unmarked row carries that row alone. Drop onto a folder row, folder tab, or another application. The receiving application decides what to do. Dropping into this window: hold **Ctrl** to copy, **Shift** to move, or **Ctrl Shift** to link; without a modifier, files move on the same device and copy across devices. An action the source does not offer copies instead.

While you hold the button on a file's icon or name, the pointer is a closed hand. The drag carries an image that trails the pointer: a card with the file's icon (its thumbnail when the list shows one) and name, the colour squares of its first three tags and the number of its tags. A drag of several files stacks two cards behind it and shows their number in an accent badge at the top right.

Reach it: Click and drag a file.

More: See [Dragging files](drag-and-drop.md).

## File chooser portal

omafiles provides the desktop file chooser portal for applications that request **OpenFile**, **SaveFile**, or **SaveFiles**. It opens a separate window: a file list, a path field, a search field, and, for SaveFile, a filename field. It has no sidebar and no view-mode switch.

Reach it: Applications using the freedesktop portal file chooser.

Keys: **Tab / Shift Tab** (move between controls), **j k / ↓ ↑ / Home End / PgDn PgUp** (move in the list), **Space** (mark, for a multiple-file or multiple-folder request), **Enter** (open a folder or choose a file), **Ctrl Enter** (choose the current folder, for a folder request), **Ctrl l** (path field), **Ctrl f** (search field), **Ctrl h** (hidden files), **Alt ↑** (parent folder), **Esc** (cancel).

More: See [File chooser portal](file-chooser.md).
